Correctness is the ordinary two-operand bf16 sum: both TP2 variants use the same packed bf16 addition (`.cuh:812/845/861`), so there is no multi-operand reduction-order ambiguity. Upstream admission requires whole 16-byte packs, at least one pack per rank, supported two-byte dtype, contiguity, matching device and capacity (`pcie_ipc_policy.py:80`, `pcie_ipc_ar.py:410`). Destroy is explicitly collective before GroupCoordinator destroys its device and CPU groups. It drains CUDA work, disposes host handle state, closes peer mappings, agrees that unmapping succeeded, then frees the local slab. No atexit or __del__ collective is installed, because GC/process exit order is not a reliable distributed protocol. Disabling the path after graphs are already captured would not rewrite those graphs; rollback means using a fresh worker with the knob off. Sleep mode is rejected at admission because raw IPC allocations are not integrated with its allocator lifecycle.
