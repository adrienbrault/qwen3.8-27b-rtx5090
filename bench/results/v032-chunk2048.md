# Smaller prefill chunks shorten response gaps at a completion-time cost

Measured 2026-10-21, results [`2026-10-21-v032-chunk2048`](2026-10-21-v032-chunk2048/). Both configurations use the same experimental native 0.32 image, TP2 MTP3, BA4 off, 15.90 GB KV pin and stock power. Only the proposed prefill token budget changes from 8192 to 2048. The completed native-8192 replay from the [upgrade screen](v032-gpu-screen.md) is reused as the control; the new boot has fresh tier and compilation directories. This is a single-pair latency screen, not a served change or qualification.

The same six-agent, three-turn replay uses matched seeds, base contexts 30K–100K, forced generation budgets and synthetic tool results. All 18 requests complete in both configurations. Gaps measure nonempty SSE frames; MTP can emit multiple tokens in a frame. The cold-turn p95 value below is the median of each of six requests' empirical p95 frame gaps, not a percentile across all requests or tokens.

| Measurement | Budget 8192 | Budget 2048 |
|---|---:|---:|
| Median cold-turn p95 response gap | 1.054 s | 0.361 s |
| Longest cold-turn response gap | 1.710 s | 0.956 s |
| Cold-turn median time to first token | 12.01 s | 13.91 s |
| Replay request-span wall time | 81.78 s | 85.73 s |
| Returning-turn median time to first token | 0.98 s | 0.94 s |

The typical cold-turn p95 gap is about 66% shorter and the worst gap about 44% shorter, while the replay takes about 4.8% longer and cold time to first token rises. This supports a latency/throughput tradeoff: smaller prefill work units let generation progress more frequently, but process the cold prompts less efficiently. This screen does not establish the same tradeoff on the served 0.31 image or across full coding-agent evaluations.

Both boots pass the arithmetic, automatic-tool and finite-logprob smoke checks. Greedy probe outputs differ in 10/12 chunks between these boots, including short prompts, so the screen does not establish bit-identical output or isolate the source of numerical differences. Both boots start with fresh compilation/autotune state. Standard numerical qualification and repeated matched measurements are needed before recommending a served change. The daily remains on 0.31 with its existing prefill budget.
